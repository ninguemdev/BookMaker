# 23 — Benchmark de Produto e Mercado

Este documento registra **o que aprender** com ferramentas existentes, não o que copiar.

## Reedsy Studio — principal referência de fluxo

Estudar:
- baixa fricção entre escrita e formatação;
- estrutura de capítulos clara;
- experiência de preview/publicação;
- decisões editoriais transformadas em presets compreensíveis;
- sensação de produto específico para autores, não editor genérico.

BookMaker deve diferenciar-se com:
- desktop/local-first;
- projeto portável;
- arquitetura futura para HQ/mangá;
- controle técnico de assets/exportação;
- possibilidade futura de fluxo roteiro -> página no mesmo projeto.

## Scrivener

Estudar:
- organização de documentos;
- hierarquia;
- navegação em manuscritos grandes;
- projetos extensos.

Evitar na V1:
- acúmulo de painéis/configurações que elevem a curva de aprendizagem.

## Atticus / Vellum

Estudar:
- transformação rápida do manuscrito em livro apresentável;
- themes;
- preview;
- redução de decisões tipográficas ruins através de bons defaults.

## InDesign

Estudar:
- conceitos editoriais profissionais;
- bleed/trim;
- masters;
- tipografia e impressão.

Não imitar:
- liberdade espacial ilimitada para a V1 de livros;
- complexidade de DTP genérico.

## Clip Studio Paint / ferramentas de quadrinhos

Estudar para V2:
- page manager;
- panels;
- balloons;
- layers;
- spreads;
- leitura RTL;
- templates.

## Hipótese de posicionamento

BookMaker ocupa o espaço entre:

```text
Editor de escrita simples
       ↓
Organização de manuscrito
       ↓
Produção editorial guiada
       ↓
Publicação
       ↓
(futuro) composição de HQ/mangá
```

## Hipóteses a validar com usuários

1. Autores valorizam local-first/offline o suficiente para diferenciá-lo de web apps.
2. Copyright/créditos integrados reduzem insegurança no momento de publicação.
3. Usuários preferem temas bem projetados a liberdade total de CSS/layout.
4. Preview + export em um só produto reduz abandono.
5. A futura ponte livro/roteiro/HQ é atraente, mas não é necessária para vender a V1.

## Pesquisa recomendada antes de beta

Entrevistar pelo menos três grupos:
- autores autopublicados;
- autores ainda escrevendo primeiro livro;
- designers/revisores/editoras pequenas.

Perguntas devem investigar fluxo atual e dores concretas, evitando perguntar apenas “você usaria BookMaker?”.
