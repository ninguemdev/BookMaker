# 08 — UX e Design do Produto

## Referência conceitual

Inspirar-se na simplicidade do Reedsy Studio: escrita e estrutura primeiro; configuração editorial exposta no momento apropriado.

Não copiar interface, assets, textos ou identidade visual de terceiros.

## Layout desktop proposto

```text
┌─────────────────────────────────────────────────────────┐
│ Top Bar: projeto | busca | preview | exportar           │
├───────────────┬───────────────────────────┬─────────────┤
│ Manuscript    │                           │ Inspector   │
│ Tree          │        Editor             │ contextual  │
│               │                           │             │
│ Chapters      │                           │             │
│ Front Matter  │                           │             │
│ Back Matter   │                           │             │
├───────────────┴───────────────────────────┴─────────────┤
│ Status: palavras | autosave | warnings                  │
└─────────────────────────────────────────────────────────┘
```

## Princípios

### Progressive disclosure
Opções avançadas aparecem somente quando necessárias.

### Contextual inspector
O painel direito muda conforme seleção:
- capítulo;
- imagem;
- projeto;
- copyright page;
- style profile.

### Autosave visível, não intrusivo
Estados:
- salvo;
- salvando;
- erro ao salvar.

Nunca exibir “salvo” antes do commit real.

### Preview como modo
Preview não deve exigir exportação toda vez.

### Empty states úteis
Exemplo no projeto novo:
- “Adicione seu primeiro capítulo”;
- “Configure os dados editoriais”;
- “Importar manuscrito” futuramente.

## Tela de publicação

Wizard curto, não obrigatório:

1. Conteúdo;
2. Dados editoriais;
3. Copyright e créditos;
4. Design;
5. Preview;
6. Exportar.

Usuário experiente pode navegar diretamente.

## Copyright UX

Tela deve apresentar campos estruturados e preview da página.

Campos:
- ano;
- titular(es);
- edição;
- publisher;
- ISBN;
- créditos;
- aviso de direitos;
- licença;
- disclaimer;
- texto customizado.

Importante: informar que a ferramenta **formata uma declaração/página de copyright** e não registra direitos autorais junto a órgãos governamentais.

## Design system

Criar tokens desde cedo:
- spacing;
- typography;
- radius;
- border;
- surfaces;
- semantic states.

Evitar CSS ad-hoc por feature.

## Atalhos

Exemplos:
- Ctrl/Cmd+B — bold;
- Ctrl/Cmd+I — italic;
- Ctrl/Cmd+K — link;
- Ctrl/Cmd+F — busca;
- Ctrl/Cmd+Shift+F — busca no projeto;
- Ctrl/Cmd+P pode ser command palette futuramente, não impressão se causar conflito de UX.

Todos os atalhos devem aparecer em menus/tooltips.
